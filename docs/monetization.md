## 二、现在就能做（按杠杆排序）

### 1. SEO 内容矩阵（长期最值钱）
- 选购指南持续更新，每周 1-2 篇原创（线路科普 / 避坑 / 优惠解读），文末带联盟 CTA
- 每家厂商生成独立静态页（/vendor/xxx，已实现），吃「厂商名 + 库存/优惠/怎么样」搜索长尾
- 持续提交 sitemap，等收录后流量复利

### 2. Telegram 补货推送机器人（私域最大杠杆）
- 用户订阅后，缺货→有货变动实时推送，消息带自有联盟链接
- 补货推送的点击转化远高于页面展示
- 待办：① @BotFather 建 bot 拿 token ② 建频道、拉 bot 当管理员 ③ token+频道 ID 交给开发
- 开发侧：Vercel Cron 定时对比库存差异 → Bot API 推送（待实现）

### 3. 扩充联盟矩阵（每家约 10 分钟接入）
- 腾讯云 / 阿里云推广：国内流量，单佣比海外 VPS 高
- DMIT / CloudCone / VMISS 联盟：与站内受众重叠度最高
- Namesilo / Namecheap 域名联盟：买 VPS 的人都要买域名，嵌进指南文章
- 接入方式：注册拿到推广链接 → 填入 config/site.ts 的 affiliate.items → 部署

### 4. 广告网络补充
- AdSense：绑定自有域名后提交审核（域名是硬条件，vercel.app 子域过不了）
- 百度联盟：门槛低，国内流量补充（AdSense 千次收益更高，优先级靠后）
